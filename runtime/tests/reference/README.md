# Историческая C reference model

Эти файлы сохранены только как независимый источник lifecycle cases при переносе
на Rust. Они не участвуют в сборке Nether, generated programs или CI и не являются
активным runtime. Актуальные primitives находятся в `runtime/src/lib.rs`, проверки —
в Rust integration tests. Контракт: [Nether → Rust](../../../docs/0.1/rust-backend.md).
