# Finalizing target

Редакция 2026-10-25. Частное правило единственной [NMM](../../core-memory-managment.md)
для Nether 0.1; альтернативных вариантов здесь нет.

Finalizing target нельзя целиком заменить, повторно инициализировать,
воскресить или передать в helper с таким effect, включая aliases.
Можно читать/менять ещё живые поля по разрешённому доступу. Body выполняется
один раз, затем очищаются оставшиеся initialized поля. Unsafe не ослабляет
этот контракт обычных safe путей.
